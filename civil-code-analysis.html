民法典第1064条与第1065条第3款竞合适用推理解析

当夫妻共同债务认定（1064条）遇上约定财产制对外效力（1065条第三款），如何确定适用顺序与责任财产范围？本推理解析完整呈现北大法宝司法实践中的裁判逻辑。

🛡️ 法律实务 · 债务隔离 · 风险防范
一、两条文的核心功能区分

在逻辑推演之前，必须先明确两个条文解决的是不同层次的问题：

条文 解决的问题 回答的问题
第1064条 债务性质认定 这笔债务是不是夫妻共同债务？
第1065条第3款 责任财产范围划定 债权人可以拿谁的财产来清偿？
关键原则：先认定性质，再确定责任财产，两步走、不倒置。
如果连"共同债务"都不是，第1065条第3款根本不会进入审查视野——这两步是有严格先后顺序的。
二、推理逻辑链：三步走

第一步  定性优先（第1064条先适用）

债权人向配偶主张债务，第一关是证明该债务属于夫妻共同债务，适用第1064条：

→
债权人向配偶主张债务承担连带责任
→
审查：债务是否符合第1064条共同债务构成要件？
↓
├
情形① 共债共签 / 事后追认
情形② 家事代理债务（为家庭日常生活需要）
情形③ 超额债务但债权人举证成功（用于共同生活/经营）
│ → 认定为共同债务，进入第二步
├
情形④ 超额债务且债权人无法证明用于共同生活/经营
│ → 认定为个人债务，债权人败诉；第1065条第3款不适用

第二步  区分适用场景

通过第一步认定为共同债务后，才进入第二步——这笔共同债务，债权人可以向谁追索、以什么财产清偿？

场景A：无约定财产制 / 债权人不知情

  • 夫妻无法定财产制，或有约定但无法证明债权人知情
  • 适用规则：共同债务 → 以夫妻共同财产 + 举债方个人财产清偿
  • 第1065条第3款条件未成就，不触发限制性适用

场景B：有约定财产制 + 债权人知情

  • 夫妻约定各自所有，且债权人知道该约定
  • 触发：第1065条第3款限缩责任财产范围
  • 债权人仅能向举债方个人财产追索，配偶个人财产豁免

第三步  第1065条第3款的限缩逻辑

第1065条第3款的功能是在认定为共同债务之后，限缩责任财产范围：

→
第一步：认定为共同债务（1064条满足）
→
夫妻约定财产归各自所有？
→
债权人知道该约定？
↓
├
是 → 第1065条第3款适用
债权人只能向举债方个人财产追索
配偶个人财产豁免（但须举证"债权人知情"）
├
否 → 不触发第1065条第3款限制
债权人可向夫妻共同财产 + 举债方个人财产追索
配偶以其在共同财产中的份额为限承担责任

⚠️ 绕过路径（最重要的实务知识点）
即使触发了第1065条第3款（债权人知情+约定各自所有），债权人仍可以绕回来援引第1064条但书：
债权人能够证明该债务用于夫妻共同生活、共同生产经营 → 债务性质升级为共同债务 → 第1065条第3款的限缩失去正当性基础

这就是(2019)最高法民申2302号确立的裁判规则：收益归家庭了，债务就是共债，第1065条第3款的保护就被架空。
四、两条文竞合的本质

竞合发生于这个精确的切点：

债务被认定为共同债务（1064条满足）
+ 夫妻约定了各自所有财产制（1065条第3款前提成立）
+ 债权人知情（触发1065条第3款限制）

三者同时满足时，两条款在逻辑上并行激活。

但它们并不冲突，因为作用于不同维度：

维度 适用条文 结论
债务性质 第1064条 认定为共同债务（成立连带责任）
责任财产范围 第1065条第3款 限缩为举债方个人财产
换个角度理解：
第1065条第3款不是在否定第1064条的认定结果，而是在第1064条认定成立之后，对外部债权人可执行范围的限缩。两步是"定性→定量"的关系——先判断"是不是"，再判断"谁来承担、用什么承担"。
五、关键司法适用要点

要点1：举证顺序不能倒置

债权人如果跳过第1064条直接主张"配偶应以其个人财产清偿"，法院会先审查债务性质。举债方配偶的抗辩也应按此顺序：

①
否定"共同债务"性质 → 争第1064条适用（先抗辩债务本身）
↓失败后
②
主张"债权人不知情" → 争第1065条第3款适用前提

这两步是递进关系，不是并列关系。实践中常见错误是把两步混在一起抗辩，导致重点不突出、举证不力。

要点2：第1065条第3款的但书——可被第1064条但书绕过

即便触发了第1065条第3款（债权人知情+约定各自所有），债权人仍可以绕回来援引第1064条但书：

债权人能够证明该债务用于夫妻共同生活、共同生产经营 → 债务性质升级为共同债务 → 第1065条第3款的限缩失去正当性基础

要点3：最终责任财产格局汇总

情形 配偶承担？ 责任财产范围
共同债务 + 无约定/不知情 ✅ 承担 夫妻共同财产 + 举债方个人财产
共同债务 + 约定各自所有 + 知情 ❌ 仅以共有份额为限 以举债方个人财产为限，配偶个人财产豁免
个人债务（第1064条但书不成立） ❌ 不承担 无（债权人对配偶无请求权基础）
共同债务 + 收益归家庭（共债成立） ✅ 承担 夫妻共同财产 + 举债方个人财产（第1065条第3款被架空）
★ Insight · 要点总结

推理的底层逻辑：两条款是"定性→定量"的关系，先用1064判断"是不是共同债务"，再用1065(3)判断"谁来承担、用什么承担"——两步走、不倒置。

竞合的触发条件：约定财产制+债权人知情+债务被认定为共同债务——三者同时满足时，两条款在逻辑上并行激活，此时第1065条第3款的限缩功能才真正发挥作用。

绕过的路径：债权人只要能举证"债务用于共同生活/经营"，即可绕过第1065条第3款的保护，适用第1064条但书重新认定为共同债务——这是实务中最常见的攻击路线，也是(2019)最高法民申2302号确立的裁判规则。

六、现行有效法条原文

民法典第1064条（核心条款，2021年1月1日施行）

夫妻双方共同签名或者夫妻一方事后追认等共同意思表示所负的债务，以及夫妻一方在婚姻关系存续期间以个人名义为家庭日常生活需要所负的债务，属于夫妻共同债务。

夫妻一方在婚姻关系存续期间以个人名义超出家庭日常生活需要所负的债务，不属于夫妻共同债务；但是，债权人能够证明该债务用于夫妻共同生活、共同生产经营或者基于夫妻双方共同意思表示的除外。

民法典第1065条第3款（约定财产制的对外效力）

夫妻对婚姻关系存续期间所得的财产约定归各自所有，夫或者妻一方对外所负的债务，相对人知道该约定的，以夫或者妻一方的个人财产清偿。

（举证责任：夫妻一方对此负有举证责任 — 婚姻家庭编解释一第37条）

婚姻家庭编解释（一）第34-37条（2021年1月1日施行）

第34条（虚构债务、违法犯罪债务排除）
夫妻一方与第三人串通，虚构债务，第三人主张该债务为夫妻共同债务的，人民法院不予支持。夫妻一方在从事赌博、吸毒等违法犯罪活动中所负债务，第三人主张该债务为夫妻共同债务的，人民法院不予支持。

第35条（离婚判决不对抗债权人）
当事人的离婚协议或者人民法院生效判决、裁定、调解书已经对夫妻财产分割问题作出处理的，债权人仍有权就夫妻共同债务向男女双方主张权利。一方就夫妻共同债务承担清偿责任后，主张由另一方按照离婚协议或者人民法院的法律文书承担相应债务的，人民法院应予支持。

第36条（一方死亡时生存方责任）
夫或者妻一方死亡的，生存一方应当对婚姻关系存续期间的夫妻共同债务承担清偿责任。

第37条（知情举证责任）
民法典第一千零六十五条第三款所称"相对人知道该约定的"，夫妻一方对此负有举证责任。
